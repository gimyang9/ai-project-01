# 차곡차곡 2.0

학습 자료의 진도와 회독을 기록하던 차곡차곡 1.0에 **시험 목표, 권장 학습량, 이해도 기반 복습, 통계와 식물 성장**을 더한 개인 학습 관리 웹앱입니다. 대학생과 여러 시험을 병행하는 학습자가 공부한 내용을 간편하게 기록하고 다음 학습을 계획하도록 돕습니다.

> 문서 점검일: 2026-10-30. 현재 소스와 기존 개발·검증 기록을 대조했습니다. 핵심 기능은 구현돼 있으나 실제 사용자 1.0 데이터 전환과 최신 버전의 iPhone Safari·설치형 PWA·게시 주소 검증은 남아 있습니다. 이번 문서 작업에서 앱 실행 테스트를 다시 수행하지 않았습니다.

## 1. 제작한 것 소개

2026-11-02 예상일 정책을 정리했습니다. 홈의 오늘의 학습은 자료명·남은 학습량·오늘 진행량·기록 버튼의 간결한 목록을 유지합니다. 자료 상세는 자동 추천/직접 설정한 분량에 따른 **계획상 예상 완료일**을 표시합니다. 하루 학습량 창에서는 저장 전에 날짜를 미리 보고, 통계에서는 **현재 회독의 실제 속도 예상일·계획상 예상일·목표일**을 비교합니다. 현재 회독 기록7일 미만이면 실제 속도 예측만 보류합니다. [현재 정책과 검증](docs/integrated-management-update.md)을 참고하세요.

홈에서 오늘의 학습량과 복습 범위를 확인하고 자료별 진도·회독·부분 복습을 기록합니다. 시험을 입력하면 여러 자료를 연결 가능하고 학습 가능한 요일과 쉬는 날짜, 시험 전 기한에 따라 권장량을 계산합니다. 이해도와 복습 이력을 기반으로 다음 복습일을 추천합니다.

통계와 캘린더는 저장된 학습·복습 이력을 집계합니다. 식물은 진행률에 따라 성장하며 최초 완성 상태를 보존합니다. 설정에서 백업·복원과 실사용 데이터에서 분리된 개발자 테스트 모드를 제공합니다. 모바일 하단 메뉴와 PC 사이드바는 홈·시험·통계·설정으로 구성됩니다.

### 1.0과 2.0 비교

비교 기준은 로컬 Git의 **2.0 작업 직전 커밋 `fe97bf2`**와 현재 `dist` 소스입니다. 당시 README에서도 자료·진도·회독·부분 복습·로컬 저장과 실행 화면을 확인했습니다.

`reference/v1`의 6개 파일 중 `app.js`, `style.css`, `favicon.svg`, 폰트 2개는 위 커밋과 Git blob 해시가 일치합니다. `index.html`은 빈 화면 설명이 다르고 보관본에 브라우저 자동 저장 안내가 추가돼 있습니다. 당시 README·실행 화면·폰트 라이선스는 보관 폴더에 없으며 Git 이력에서 확인됩니다. **실제 제출 커밋·제출 링크의 근거가 없어 보관본 전체가 실제 이전 제출본과 동일하다는 판정은 보류합니다.**

### 기술과 실행

HTML·CSS·일반 JavaScript와 브라우저 로컬 저장을 사용합니다. 2026-11-01 사용자 지정 배포 기준은 GitHub Pages `main / (root)`이며 `dist`에도 동일한 식물 연결 수정을 반영했습니다. Python이 설치돼 있다면 프로젝트 루트에서 실행합니다.

```powershell
python -m http.server 8000
```

`http://localhost:8000`을 엽니다. 같은 주소·포트·브라우저를 사용해야 같은 저장소에 접근합니다. 통합 키는 `chagok-v2-data-v1`, 테스트 ON은 탭 전용 SessionStorage입니다. 설정의 개발자 테스트를 ON하면 가상 자료 7개·시험 3개로 시연합니다. ON마다 초기화되고 OFF는 실사용 환경으로 돌아갑니다. [사용 안내](docs/developer-test-data-implementation.md)를 참고하세요.

PWA는 HTTPS 또는 localhost에서 동작합니다. 코드·스타일·에셋 변경 후 게시 전 `node scripts/build-pwa.cjs`로 캐시를 갱신합니다. 2026-11-01 식물 연결 수정에서 양쪽 캐시를 갱신하고40PNG 오프라인 로딩을 검증했습니다. 주요 모듈은 [데이터](dist/study-data.js), [학습 계획](dist/learning-plan.js), [복습](dist/review-plan.js), [통계](dist/study-stats.js)이며 이미지·폰트 출처는 [ASSETS.md](ASSETS.md)에 있습니다.

## 3. TODO 변경 내역

[기존 변경 이력](docs/TODO-changes.md)에 변경 전후·이유·검증 근거를 보존했습니다. 주요 변화는 다음과 같습니다.

- **단순화:** 시험 중요도 3단계를 하나의 우선 시험으로 대체하고 확정/예상/미정 선택은 날짜 입력·미입력으로 정리했습니다. 시험 중단 시 계속 학습할 자료는 매번 직접 선택합니다.
- **규칙 확정:** 제안 단계였던 복습 간격을 사용자 확인 후 최초 1/3/7일·이후 이해도별 배수로 정했습니다. 집중 복습은 고정 D-7/D-14 대신 실제 속도·학습 가능일·여유일로 역산합니다.
- **테스트 후 수정:** 저장 충돌 시 입력을 보존하고 자정 갱신·집중 복습 완료 범위를 보호했습니다. 늦은 자료 목표일보다 시험 전 기한을 우선하며 오늘 학습량의 이중 차감을 방지했습니다. 다시 연 메모의 미저장 보호와 설정 제목 줄바꿈도 수정했습니다.
- **추가·대체:** 날짜별 완료 기록 조회·쉬는 날짜 달력을 추가했습니다. 별도 개발 앱·다중 시나리오 도구는 제거하고 설정의 단일 OFF/ON 테스트로 대체했습니다. 더보기 중간 메뉴는 설정 직접 화면으로 바꿨습니다.

상세 TODO는 복원·현행화 문서이므로 당시 원문과 완전히 같은 최초 계획이라고 주장하지 않습니다. 사소한 치수 변경은 반복하지 않고 기존 보고서로 연결합니다.

# 차곡차곡 데이터·기록 보호

이 파일은 2026-10-24 새로 작성한 프로젝트용 버전이다. 과거 CG-SKILL-001~012에서 사용했다는 원문을 복원한 파일이 아니다.

## 작업 범위 결정

프로젝트 루트의 최신 사용자 지시, `PROGRESS.md`, `docs/TODO.md`에서 이번 작업 범위와 번호를 확인한다. 관련 요구사항만 `docs/PRD.md`, `docs/PRD-updates.md`에서 읽는다. 후속 결정이 초기 기획보다 우선한다. 스킬 준비·보고서 정리는 다음 앱 구현 단계의 승인이 아니다. Git 커밋은 사용자가 직접 담당한다는 현재 지시를 따른다.

현재 상태를 고정된 전제로 재사용하지 말고 소스를 확인한다. 조사 시작점은 `dist/app.js`의 예시 자료와 폼 submit 처리, `dist/exam-management.js`의 KEY/load/save/upgrade, `reference/v1/app.js`의 저장·백업 코드다. 실제 브라우저 저장값을 읽어야 하는 작업인지, 소스나 합성 데이터만으로 가능한지 구분한다.

## 데이터 변경 시 지켜야 할 조건

- `reference/v1` 원본 소스를 변경하지 않는다. 마이그레이션은 사용자 데이터 복사본 또는 합성 데이터로 검증하고 기존 저장값을 성공 확인 전에 덮어쓰지 않는다.
- 자료 ID, 원본 기록 ID·날짜·시각·순서·단위·범위·이해도·회독 이력과 알 수 없는 기존 필드의 보존 방침을 정한다. 파생 상태를 계산하려고 원본 평가를 수정하지 않는다.
- 부분 복습은 전체 진도·회독을 바꾸지 않는다. 다음 회독을 시작해도 과거 회독 기록을 지우지 않는다. 수동 계획·복습일·메모를 자동 추천으로 덮어쓰지 않는다.
- 직접 중단 상태가 자동 중단보다 우선한다. 다중 시험 연결에서는 다른 활성 시험과 시험별 계속 학습 선택을 고려한다. 재개는 해당 시험의 자동 중단 영향만 해제한다.
- 일반·시험 전 복습이 같은 날짜와 범위에서 겹칠 때 추천 표시와 실제 기록을 구분해 이력 중복 생성을 방지한다.
- 미확정 복습 간격·초기 속도·여유일은 `PRD-updates.md`에 따른 사례 확인 전 확정값으로 구현하지 않는다. 고정 D-7/D-14 규칙으로 대체하지 않는다.
