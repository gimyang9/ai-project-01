## 기능 검증의 현재 한계

- 네 탭, 입력 모달, 시험 관리와 반응형은 기존 QA 기록이 있으나 이번 브라우저 재실행은 하지 않았다.
- 학습 자료 CRUD·진도·복습 저장·기존 데이터 전환·전체 백업 왕복은 구현 미완료이므로 통과로 표시하지 않는다.
- 기존 자동 테스트 재실행은 `node` 명령 부재로 시작하지 못했다.
- 실제 Safari·설치형 PWA·콘솔 오류 검증과 최종 통합 시나리오는 확인 필요다.
- 외부 공개 전 비밀키·토큰·환경변수·개인정보 점검은 아직 수행하지 않았다.
