# 차곡차곡 2.0 — 통합 TODO (변경 사항 표시)

> **정리 기준: 2026-10-30 기록**  
> 중간고사 과제 제출을 위해 기존 단계별 TODO와 후속 변경 이력을 **하나의 실행 가능한 체크리스트**로 합쳤다. 원래의 단계 번호는 유지하고, 이후 승인·구현한 작업은 관련 단계 하위에 통합했다. 기존 기록에 나타난 자동 테스트와 Chrome 검증은 **당시 기록**이며 이번 문서 작성 과정에서 재실행한 결과가 아니다.
>
> **범례:** `[추가]` 새로 만든 항목 · `[변경]` 기존 계획/기능 변경 · `[삭제]` 실제 제거 · `[개선]` 테스트·사용 후 수정. **변경 이유는 기록하지 않고 전후 차이만 표시한다.** 변경되지 않은 항목은 별도 표기를 하지 않는다. `[x]`는 문서에 근거가 있는 **구현 또는 해당 범위 합성 검증 완료**, `[ ]`는 **미완료/최종 확인 대기**를 뜻한다. `[삭제]`는 삭제 작업이 이행됐다는 뜻으로 `[x]`를 붙일 수 있다.
>
> **정확성 유의:** 이 문서는 기존 TODO의 완전한 원본 복제본이 아니라, 남아 있는 PRD·후속 결정·작업 기록으로 재구성한 통합본이다. 1.0 대비 변경과 **2.0 초기 계획 대비 변경**은 서로 다른 비교 기준이다. 실제 iPhone Safari, 게시된 GitHub Pages와 1.0 실제 사용자 데이터 이전 검증은 완료로 간주하지 않는다.
