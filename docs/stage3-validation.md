## 계산 기준 확인 대기 — 답변 전 이력

PRD #9는 여러 시험의 권장량 중복 방지와 학습 속도 예측 기간/예외 처리를 구현 전 확정할 대상으로 지정한다. PRD-updates.md는 “최초 복습 간격, 증가·감소율, 장기 제한, 예측 기간과 초기 추정량의 구체 수치는 아직 확정하지 않았다. 이전 제안 수치를 확정값으로 구현하지 않는다.”고 명시한다. 따라서 다음 두 항목을 사용자에게 비동기 질문으로 요청했고 아직 답변을 받지 않았다.

1. 권장량 제안: 오늘부터 시험 전날까지 가능한 날로 남은 분량을 나눈다. 자료 목표일은 당일 포함하며 시험일보다 우선한다. 여러 시험이면 가장 이른 기준일로 자료당 한 번만 추천한다. 예: 100페이지/5일=하루 20페이지. 대안은 시험일 당일도 포함하는 방식이다.
2. 예상 완료일 제안: 최근 14일 또는 28일 평균. 쉬는 날도 분모에 포함하고 기록이 부족하면 임의 초기 속도 없이 추정 불가로 표시한다.

## 사용자 확정 후 최종 구현·검증 — CG-SKILL-019

| 자료의 실제 학습 기록 기간 | 평균 기간 |
|---|---|
| 7일 미만 | 추정할 기록 부족, 예상일 없음 |
| 7~13일 | 최근 7일 |
| 14~27일 | 최근 14일 |
| 28일 이상 | 최근 28일 |

기록 기간은 최초 학습 기록일부터 오늘까지 양끝 포함으로 계산한다. 시험 생성일/준비 기간이나 자료 등록일은 사용하지 않는다. 현재 회독과 roundHistory의 학습 날짜를 사용하고 부분 복습은 기간/속도 양쪽에서 제외한다. 최근 평균은 선택 기간의 학습량을 7/14/28로 나누므로 빈 날·쉬는 날을 포함한다. 같은 날 복수 진도는 position 합계 대신 순서별 차이(amount)를 합산한다. 과거 회독 단위가 현재 단위와 다르면 그 분량은 속도에 더하지 않는다. 최근 분량이 0이면 예상일 없음. 충분한 기간과 분량이 있으면 오늘부터 ceil(남은 분량/속도)일 뒤를 추정한다. 지원 날짜 범위를 넘으면 예상일 없음으로 처리한다.

권장량은 이 추정과 독립적으로 ceil(남은 분량/학습 가능일)이다. 시험 전날까지 세되 자료 목표일이 있으면 그 날짜를 우선하고 당일까지 센다. 활성 시험 중 가장 이른 시험이 기준 요일/쉬는 날짜를 제공하고, 날짜 있는 시험이 없으면 우선 정렬된 활성 시험을 사용한다. 독립 자료는 모든 달력일을 사용한다. 우선 시험은 목록 순서에만 적용하며 더 이른 기한을 무시하지 않는다. 기한 지난 시험은 임의로 다음 시험으로 건너뛰지 않고 조정을 안내한다.

현재 진도 변경 때마다 남은 분량과 자동 권장량을 재계산한다. 예: 100/5일=20, 20페이지 기록 후 남은80/5일=16. 이 값은 남은 분량 기준의 갱신된 권장량이며 고정된 하루 목표 완료 판정이 아니다. 직접 정한 하루 분량은 고정된 수동 목표로 저장하고 오늘 기록량만 차감한다. 자동 계산은 이를 덮어쓰지 않는다. 부족량/현재 속도의 기한 초과도 안내한다. 학습 불가능한 일정에서는 0으로 나누거나 임의 추천을 하지 않는다.

### UI와 저장

- learning-plan.js는 원본/파생을 분리하는 순수 함수다. 계산 결과는 저장하지 않고 기록과 수동 설정에서 매번 만든다.
- 자료의 manualDailyAmount만 선택 필드로 저장한다. 1 이상의 정수 또는 null이며 없으면 자동이다. 원본 학습/복습/회독/이해도와 시험 수동 일정은 보존한다.
- 홈에서 자료별 비중복 권장량, 남은 분량, 예상일/추정 부족·0분량 안내를 표시한다.
- 시험 연결 자료·자료 상세 기본 정보에서도 동일 계획과 기준일/부족 안내를 표시한다. 자료 관리에 학습 계획 메뉴를 추가했다.
- 학습 계획에서 수동 하루 분량 설정 및 빈 값으로 자동 복귀가 가능하다. 정상 저장 후에만 화면 상태를 바꾸고 백업/복원·재로드에서 설정을 유지한다.
- 4단계 자동 복습은 준비 중이며 통계/캘린더 예시 안내는 유지한다.
