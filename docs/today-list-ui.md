# 홈 오늘의 학습 표시 개선

2026-10-25. D:/Projects/project-v2-upload로 이동한 프로젝트에서 중단된 작업을 이어 진행했다.

- 각 자료는 자료명/진도 기록 동작과 '남은 분량 · 짧은 계획 상태'로 표시한다.
- 예: 남은 120페이지 · 오늘 권장 15페이지, 남은 25강 · 목표일 미정, 남은 70페이지 · 오늘은 쉬는 날.
- 수동 계획은 오늘 기록량을 이미 차감한 기존 amount를 표시한다. 오늘 설정 분량을 채우면 완료 상태를 표시한다.
- 기한 초과/학습 가능일 없음/기한 내 부족 분량/완료 지연 예상은 보조 줄에 짧게 표시한다.
- 남은 분량0과 비활성 자료는 기존처럼 오늘 목록에서 제외한다. 등록 자료는 있지만 모두 완료/비활성인 경우 '오늘 진행할 학습이 없어요.'로 표시한다.
- 최근7/14/28일 학습량과 기록 부족·예상일 장문은 홈에서 제거했다. 기존 dailyPlanLabel/forecastLabel/planWarning/compactPlanStatus와 학습 계획 모달은 변경하지 않았다.
- 새 homePlanLabel은 파생 계획을 읽기만 한다. LearningPlan/StudyData 모듈과 데이터 구조·저장 동작은 그대로다.
- 스타일은 #view-home #today-list .today-task-compact에만 추가했다. 기존 줄 구분선/행 바깥 여백/색상/아이콘을 유지하고 자료명 줄바꿈·보조 문구 자연스러운 줄바꿈을 허용한다. 오른쪽 진도 기록 동작은44px 이상 터치 영역과 글자/화살표 정렬을 유지한다.
- 루트와dist app.js는 동일하다. CSS는 기존 루트의 별도 모달 수정 차이를 보존하기 위해 각각 동일한 홈 전용 규칙을 추가했다. 전체 CSS 파일을 덮어써 동기화하지 않았다.

검증: 기존92개와 신규2개를 포함해94개 테스트 통과. 신규 검사는 요청한7가지 상태와0분량 제외, 문자 이스케이프, 원본 상태/저장값 불변, 긴 홈 안내 제거와 기존 상세 안내 유지를 확인한다. 이전 통합 테스트의 홈 기대값도 새 표시 정책으로 갱신했다.

실제 브라우저 도구가 제공되지 않고 Playwright도 설치돼 있지 않아 모바일/PC 렌더링·키보드/화살표 위치·가로 넘침을 실제 화면에서 확인하지 못했다. 테스트의 모의 DOM은 실제 화면 검증이 아니다. Git 커밋·배포는 수행하지 않았다.
