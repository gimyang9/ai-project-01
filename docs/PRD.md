## 0. AI에게 보내는 요청

당신은 이 프로젝트를 함께 만드는 개발 담당자입니다. 아래 요구사항 문서를 읽고,

1. 이해한 내용을 3~5줄로 요약해서 확인받으세요.
2. 문서에서 불명확하거나 결정이 필요한 부분이 있다면, 작업 시작 전에 저에게 질문하세요.
3. 확인이 끝나면 구현 계획(단계별 할 일 목록)을 먼저 제안하고, 제가 승인하면 작업을 시작하세요.

5. 개발 과정에서 요구사항이 변경되면 PRD와 TODO 리스트에 반영하고, 기존 계획과 달라진 내용을 기록하세요.
6. 기존 v1의 기능과 사용자 데이터가 손상되지 않도록 주의하고, 주요 기능을 수정한 뒤에는 동작 여부를 확인하세요.

## 1. 프로젝트 개요

- **프로젝트 이름:** 차곡차곡 v2 (학습 관리 앱)
- **한 줄 소개:** 학습 진도를 기록하고 시험 일정과 이해도를 바탕으로 학습량과 복습 일정을 추천하는 학습 관리 웹앱
- **만드는 사람:** 개인 프로젝트
- **완성 목표일:** 2026-11-02

## 2. 왜 만드나요? (목적)

전공 공부와 자격증, 여러 시험을 함께 준비하다 보면 교재마다 얼마나 공부했는지, 언제까지 끝내야 하는지, 어떤 내용을 다시 복습해야 하는지 관리하기 어렵습니다.

기존 v1은 학습 자료별 진도와 회독을 간편하게 기록할 수 있었지만, 시험 일정에 맞춰 학습량을 계획하거나 복습할 시점을 알려주는 기능은 부족했습니다.

그래서 v2에서는 기존 기록 기능을 유지하면서 **시험 관리, 일일 학습량 추천, 이해도 기반 복습, 학습 통계**를 추가하고자 합니다.

사용자가 공부한 내용을 간단히 기록하면, 앱이 이를 바탕으로 앞으로 얼마나 공부해야 하고 무엇을 복습해야 하는지 알려주는 것이 목표입니다.

## 3. 누가 사용하나요? (사용자)

- **주 사용자:** 여러 교재와 강의를 병행하는 대학생 및 취준생
- **사용 환경:** 스마트폰 중심으로 사용하며 PC에서도 이용할 수 있는 반응형 웹앱
- **사용자에 대해 알아야 할 점:**
  - 학습 자료마다 분량과 단위가 다릅니다.
  - 하나의 교재를 여러 시험 준비에 사용할 수 있습니다.
  - 매일 일정한 분량을 공부하기 어렵고, 계획이 자주 바뀔 수 있습니다.
  - 복잡한 설정이나 반복 입력 없이 빠르게 기록하기를 원합니다.
  - 학습량을 자동으로 추천받되, 필요하면 직접 수정할 수 있어야 합니다.

### 3-1. 대표 사용자 페르소나

- **이름/나이:** 대학생 A, 24세 (가상 인물)
- **상황:** 대학 생활과 함께 자격증 및 여러 시험을 준비하고 있습니다. 학기 중에는 여러 공부를 병행하지만, 중간·기말고사 기간에는 대학 시험에 집중하고 싶습니다. 또한 매일 일정한 분량을 꾸준히 공부하기보다는 상황에 따라 학습량과 계획을 조정하는 편입니다
- **바라는 것:** 시험 일정에 따라 학습 우선순위를 조정하고, 실제 진도에 맞춰 학습량과 복습 일정을 추천받고 싶습니다. 추천된 계획을 필요에 따라 직접 수정할 수 있고, 학습 과정에서 성취감과 동기부여도 얻을 수 있기를 바랍니다.
- **불편해하는 것:** 학습 계획을 일일이 세우거나 복습 일정을 직접 계산하는 것이 번거롭습니다. 그렇다고 정해진 계획을 반드시 따라야 하거나 앱이 모든 것을 자동으로 결정하는 방식도 원하지 않습니다. 계획을 지키지 못했을 때 유연하게 조정할 수 없는 점도 불편합니다.

## 4. 꼭 있어야 하는 기능 (핵심 기능)

### 4-1. 학습 자료 및 진도 관리

사용자는 교재, 문제집, 인터넷 강의 등의 학습 자료를 등록하고 공부한 분량과 회독을 기록할 수 있습니다.

- 자료별 전체 분량, 현재 진도, 진행률 및 회독 관리
- 날짜별 학습 기록, 부분 복습 및 메모 작성
- 학습 완료·재시작·일시 중단·보관 및 복원
- [추가] 학습 중인 자료와 완료된 자료를 구분하여 관리
- [개선] 학습 기록과 복습 이력을 쉽게 조회·수정

### 4-2. 시험 관리 및 학습량 추천

사용자는 준비하는 시험과 학습 자료를 연결하고, 시험일까지 필요한 일일 학습량을 추천받을 수 있습니다.

- 시험 등록·수정, 시험일 및 D-Day 관리
- 하나의 학습 자료를 여러 시험에 연결
- 시험일, 목표 완료일, 남은 분량, 쉬는 날짜를 반영한 권장 학습량
- 실제 학습 기록에 따라 오늘 남은 학습량과 계획 자동 재계산
- 자동 추천 외에도 사용자가 일일 학습량 직접 설정 가능
- 실제 학습 속도와 설정된 학습 계획에 따른 예상 완료일 확인
- 시험 중단·재개·마무리·재응시 및 우선 시험 관리

**개발 중 주요 변경**

- [변경] 시험 날짜의 확정·예상·미정 상태 구분을 없애고 날짜 입력을 선택사항으로 단순화
- [변경] 시험 중요도 3단계 대신 우선 시험 하나를 지정하도록 수정
- [변경] 완료 기한은 자료 목표일과 시험 전날 중 더 이른 날짜를 적용
- [개선] 오늘 이미 공부한 분량을 반영해 실제 남은 권장량 표시
- [개선] 예상 완료일은 실제 학습 속도 기준과 자동·수동 학습 계획 기준을 구분

### 4-3. 이해도 기반 복습 추천

사용자는 학습하거나 부분 복습한 범위의 이해도를 선택하고, 이를 바탕으로 다음 복습 시점을 추천받을 수 있습니다.

- 학습 범위별 이해도(쉬움·보통·어려움) 기록
- 이해도 및 이전 복습 이력을 바탕으로 다음 복습일 자동 계산
- 오늘 예정된 복습과 밀린 복습 구분
- 복습 예정일 직접 변경 및 완료 후 일정 재계산
- 시험 일정에 맞춘 집중 복습 추천
- 같은 범위의 일반 복습과 집중 복습 중복 방지

**개발 중 주요 변경**

- [변경] 복습 간격을 이해도별 계산 규칙으로 구체화
- [변경] 시험 전 집중 복습은 고정 기간 대신 실제 복습 속도와 학습 가능한 날짜를 반영하도록 개선
- [개선] 범위가 겹치면 기존 기록은 보존하고 최신 이해도를 적용

### 4-4. 학습 현황·통계·캘린더

사용자는 자신의 학습 진행 상황과 과거 기록을 다양한 방식으로 확인할 수 있습니다.

- 홈에서 오늘의 학습량, 복습 일정 및 다가오는 시험 확인
- 주간·월간·최근 3개월·6개월 학습 통계
- 학습량 추이 및 과목·시험별 학습 비중 확인
- 캘린더에서 날짜별 학습·복습 기록 조회

### 4-5. 학습 진행 시각화

사용자는 학습 자료의 진행률에 따라 성장하는 픽셀 식물을 통해 학습 진행 상황을 시각적으로 확인할 수 있습니다.

- 자료 등록 시 식물 자동 배정
- 진행률에 따라 식물이 5단계로 성장
- 자료의 최초 전체 진도 완료 후 완성 상태 보존
- 학습 자료 카드와 홈 화면에 성장 상태 표시

## 5. 만들지 않는 것 (범위 제외)

이번 v2에서는 학습 진도와 시험·복습 관리에 집중하기 위해 다음 기능은 만들지 않습니다.

- 회원가입·로그인 및 서버 기반 데이터 동기화
- 학습 시간 측정 타이머
- 유료 API 및 유료 서비스 연동
- 사용자가 직접 식물 종류를 선택하는 기능
- 복습 성공 횟수 등을 직접 입력하거나 표시하는 기능

## 6. 모양과 분위기 (디자인)

- **원하는 느낌:** 따뜻하고 차분하며 아기자기하지만, 학습 관리 앱으로서 정보가 깔끔하게 정리된 디자인
- **주요 색상:** 아이보리·크림·브라운 중심, 세이지 그린 보조
- **글꼴:** 제목 카페24 써라운드, 본문 LINE Seed Sans KR
- **시각적 요소:** 일러스트 삽입 시 픽셀 형태, 둥근 카드와 자연스러운 여백
- **화면 구성:** 모바일 하단 내비게이션과 PC 사이드바를 사용하며 홈·시험·통계·설정으로 구성

**디자인에서 지켜야 할 점**

- 단순히 귀여운 화면보다 학습 정보를 쉽게 파악할 수 있는 화면을 우선합니다.
- 학습 기록은 최소한의 조작으로 완료할 수 있어야 합니다.
- 모바일과 PC의 화면 너비에 맞춰 배치와 여백을 자연스럽게 조정합니다.
- 긴 자료명이나 좁은 화면에서도 중요한 정보와 버튼이 잘리지 않아야 합니다.

## 7. 기술 조건

- **결과물 형태:** 스마트폰과 PC에서 사용할 수 있는 반응형 웹앱(PWA)
- **사용할 언어:** HTML, CSS, JavaScript
- **데이터 저장:** 브라우저 LocalStorage

**지켜야 할 조건**

- 별도의 서버나 로그인 없이 사용할 수 있어야 합니다.
- 브라우저를 닫았다가 다시 열어도 저장한 기록이 유지되어야 합니다.
- 데이터를 JSON 파일로 백업·복원할 수 있어야 합니다.
- 기존 v1의 데이터를 가능한 한 안전하게 연계해야 합니다.
- PWA 설치 및 오프라인 실행을 지원해야 합니다.
- 새로운 기능을 추가하더라도 기존 진도 기록 기능이 정상적으로 유지되어야 합니다.
- 테스트 데이터는 실제 사용자 데이터와 구분하여 관리합니다.

## 8. 가정한 것들

- 사용자는 주로 개인 스마트폰이나 PC에서 앱을 사용한다고 가정합니다.
- 학습 자료의 전체 분량과 실제 공부한 진도는 사용자가 직접 입력한다고 가정합니다.
- 학습량과 복습 추천은 사용자가 기록한 데이터를 기준으로 계산합니다.
- 매일 같은 분량을 공부하지 않을 수 있으므로 쉬는 날짜와 학습 계획 변경을 허용합니다.
- 시험 날짜가 정해지지 않은 자료도 독립적으로 관리할 수 있어야 합니다.
- 여러 시험이 동일한 학습 자료를 공유할 수 있다고 가정합니다.
- 데이터는 브라우저에 저장되므로 브라우저 데이터 삭제나 기기 변경에 대비해 사용자가 백업할 수 있어야 합니다.

## 9. 결정하거나 조사해야 할 것 (열린 질문)

개발 중 주요 기능과 정책은 대부분 결정했으며, 최종 확인이 필요한 항목은 다음과 같습니다.

- 기존 v1의 실제 사용자 데이터를 v2으로 전환했을 때 기록이 모두 유지되는가?
- GitHub Pages에 게시한 버전에서 최신 이미지와 수정 사항이 정상적으로 반영되는가?
- 모바일과 다양한 PC 화면 너비에서 레이아웃이 깨지거나 조작이 어려운 부분은 없는가?
- 실제 사용 과정에서 학습량과 복습 추천이 이해하기 쉽게 표시되는가?
