## 1. 프로젝트 개요

- 프로젝트 이름: 차곡차곡 2.0
- 한 줄 소개: 학습 진도와 시험 목표를 관리하고, 이해도에 따라 복습 일정과 학습량을 추천하는 학습 관리 웹앱
- 만드는 사람: 개인 프로젝트
- 완성 목표일: 과제 제출일까지

## 2. 왜 만드나요? (목적)

전공 공부와 여러 시험을 병행하면서 학습 자료별 진도, 복습이 필요한 범위, 시험일까지 남은 학습량을 정확히 파악하고 관리하기 어렵다는 문제에서 출발했다.

기존 차곡차곡 1.0의 간편한 진도 기록 기능을 유지하면서 시험 목표 관리와 이해도 기반 학습·복습 추천을 추가해, 단기 및 장기 학습을 체계적으로 관리하고자 한다.

핵심은 공부를 마친 뒤 간편하게 기록하고, 전체적인 학습 상황을 한눈에 확인하는 것이다.

## 3. 누가 사용하나요? (사용자)

- 주 사용자: 대학생, 자격증 및 공무원 시험 준비생
- 사용 환경: 스마트폰 중심, PC에서도 사용
- 사용자에 대해 알아야 할 점: 여러 학습 자료와 시험을 병행하며, 복잡한 설정이나 반복 입력 없이 진도와 복습 상황을 확인하고 싶어 한다.

### 3-1. 대표 사용자 페르소나

- 이름/나이: 대학생 A / 23세
- 상황: 전공 시험과 자격증을 함께 준비하며 여러 교재와 인터넷 강의를 공부한다.
- 바라는 것: 공부 후 진도를 간단하게 기록하고, 오늘 공부할 분량과 복습할 범위를 추천받고 싶다.
- 불편해하는 것: 복잡한 학습 계획표, 번거로운 기록 과정, 파악하기 어려운 학습 현황

## 4. 꼭 있어야 하는 기능 (핵심 기능)

### 4-1. 사용자는 학습 자료별 진도와 회독을 기록하고 관리할 수 있다. [기존 유지·개선]

- 교재·문제집·인터넷 강의·단어 학습·기타 자료 등록, 수정, 삭제
- 학습 유형에 따른 단위 및 전체 학습 분량 설정
- 날짜와 범위에 따른 진도 기록·수정·삭제
- 현재 진도, 진행률, 회독 횟수 및 과거 기록 확인
- 전체 회독 및 부분 복습 기록 관리
- 자료별 목표 완료일 설정, 일시 중단·보관·복원
- 기존 백업·복원 및 데이터 초기화 기능 유지

### 4-2. 사용자는 시험 목표를 설정하고 권장 학습량을 확인할 수 있다. [추가]

- 시험일 확정·예상·미정, D-Day 및 목표 중요도 설정
- 하나의 학습 자료를 여러 시험 목표에 연결하거나 독립적으로 관리
- 남은 학습 분량, 자료별 목표 완료일, 학습 가능일에 따른 일일 권장 학습량 자동 계산
- 실제 진도에 따른 계획 재계산 및 예상 완료일 표시
- 시험 목표별 집중 기간, 쉬는 날 및 일시 중단 설정
- 목표 중요도에 따른 오늘의 추천 학습 순서 조정
- 달성하기 어려운 일정에 대한 안내 및 사용자 수동 설정 보존
- 시험 종료 후 사용자 선택에 따른 완료·보관
- ‘다시 준비하기’ 기능으로 재응시 목표 생성 및 선택한 기존 자료·이력 승계

### 4-3. 사용자는 이해도에 따라 복습 일정을 추천받을 수 있다. [추가]

- 진도 기록과 부분 복습 기록 시 쉬움 / 보통 / 어려움 선택(선택사항)
- 이해도 및 복습 이력을 반영한 적응형 복습 주기 자동 계산
- 장기 학습을 고려해 복습 간격을 수주·수개월 이상 유연하게 조정
- 과거 기록을 보존하면서 겹치는 학습 범위에 최신 이해도 적용
- 같은 날짜의 복수 평가는 기록 시각과 순서로 구분
- 겹치는 구간의 복습 상태와 일정만 재계산
- 미완료·지연 복습 표시 및 수동 복습일 변경
- 시험일이 가까우면 기존 복습 주기를 유지하면서 별도 시험 전 복습 추천
- 여러 시험에 연결된 자료는 가장 가까운 유효 시험일을 우선 고려
- 복습 계산에 필요한 내부 값은 사용자가 입력하거나 확인할 필요 없이 자동 관리

### 4-4. 사용자는 전체 학습 현황과 통계를 확인할 수 있다. [추가]

- 오늘의 권장 학습과 복습 일정, 시험별 D-Day 표시
- 학습 목표별 진행 상황과 학습 자료별 진도 확인
- 학습·복습 기록을 확인하는 캘린더
- 주간·월간·최근 3개월·6개월 학습 통계
- 과목·시험 목표별 학습 비중 및 학습 추이
- 주간 학습 요약 및 현재 학습 속도에 따른 예상 완료일

### 4-5. 사용자는 학습 진행 상황을 시각적으로 확인할 수 있다. [디자인 개선]

- 자료 등록 시 픽셀 식물을 자동 배정
- 학습 진행률에 따라 식물이 단계적으로 성장
- 최초 전체 진도 완료 시 완성된 식물 상태 유지
- 자료 보관 시 식물도 보관하고 삭제 시 함께 제거
- 픽셀 숲 배너, 식물 성장 표시, 직관적인 학습 자료 카드 제공
- 별도의 정원 화면 없이 기존 학습 관리 화면에 자연스럽게 통합

## 6. 모양과 분위기 (디자인)

- 원하는 느낌: 따뜻하고 포근한 픽셀 숲 분위기. 아기자기하면서도 정보가 명확하게 구분되는 직관적인 UI
- 주요 색상: 아이보리·크림·브라운·세이지그린·올리브그린
- 색상 구성: 아이보리와 크림을 기본 배경으로 사용하고, 브라운으로 글자와 화면 구조를 잡으며, 녹색은 식물·진도·강조 요소에 포인트로 활용한다. 머스타드·테라코타 등의 색상도 소량 사용해 자연스럽고 다채로운 분위기를 만든다.
- 디자인 원칙: 화면 전체가 녹색 위주로 보이지 않도록 한다. ‘초록색 앱’이 아닌 ‘아이보리·브라운·그린이 조화로운 따뜻한 숲 감성 앱’을 지향한다.
- 참고 이미지: 함께 제작한 차곡차곡 2.0 전체 화면 디자인 시안
- 폰트: 제목 카페24 써라운드 / 본문 LINE Seed Sans KR
- 화면 구성: 홈 / 목표 / 통계 / 더보기의 하단 내비게이션
- 세부 요소: 둥근 카드, 충분한 여백, 독립된 둥근 픽셀 숲 배너, 식물 성장 이미지, 덩굴 형태의 진행률 표시
- 버전 표시: 화면 상단 오른쪽에 작고 연한 색상으로 v2.0.0 표시
- 사용성: 모바일에서도 입력하기 편리하고, 진도 기록과 이해도 선택에 불필요한 단계가 없어야 한다.

## 7. 기술 조건

- 결과물 형태: 모바일·PC 반응형 웹앱(PWA)
- 사용할 도구나 언어: HTML, CSS, JavaScript
- 배포 방식: 기존 GitHub Pages 배포 구조 유지
- 데이터 저장: LocalStorage 기반 로컬 저장
- 지켜야 할 조건:
  - 기존 차곡차곡 1.0의 데이터, 핵심 기능, 백업·복원 기능 유지
  - 기존 데이터 손실을 방지하는 안전한 데이터 마이그레이션 적용
  - 스마트 복습 및 권장 학습량 계산 로직을 분리해 구현·테스트
  - 픽셀 아트는 개별 이미지 에셋, 일반 UI 아이콘은 SVG 등을 활용
  - 유료 서비스 없이 사용 가능해야 함

## 8. 가정한 것들

- 학습 자료와 시험 목표는 독립적으로 관리하며, 하나의 자료를 여러 시험에 연결할 수 있다.
- 부분 복습은 전체 진도·진행률·회독 횟수를 변경하지 않는다.
- 시험일은 확정·예상·미정 상태를 가지며, 미정인 경우에도 학습 기록은 가능하다.
- 자료별 목표 완료일이 있으면 해당 날짜를 학습량 계산에 우선 적용한다.
- 권장 학습 순서는 목표 중요도에 따라 조정하되, 동일한 학습량을 중복 계산하지 않는다.
- 이해도는 학습 범위별로 관리하고, 원본 평가 기록을 보존하면서 최신 상태를 반영한다.
- 스마트 복습은 간격 반복 학습의 과학적 원리를 참고한 경량 적응형 알고리즘으로 설계하며, 개인별 최적 복습일을 보장하지 않는다.
- 복습 예정일을 놓치면 지연 상태를 유지하고, 완료한 날짜를 기준으로 이후 일정을 조정한다.
- 사용자가 직접 설정한 학습 계획 및 복습 날짜는 자동 재계산보다 우선한다.
- 장기 시험 준비, 재응시, 학습 자료 보관·복원 시 기존 학습 이력을 초기화하지 않는다.
- 학습 속도 예측은 쉬는 날을 포함한 최근 기간의 일평균을 기준으로 한다.
