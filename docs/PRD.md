## 1. 프로젝트 개요

- **프로젝트명:** 차곡차곡 2.0
- **한 줄 소개:** 학습 자료별 진도를 기록하고 시험 일정과 이해도를 바탕으로 학습량·복습 일정을 추천하는 모바일 중심 학습 관리 웹앱
- **개발 형태:** 개인 바이브 코딩 프로젝트
- **기반 프로젝트:** 차곡차곡 1.0을 발전시킨 버전
- **기술:** HTML, CSS, JavaScript, LocalStorage, PWA, GitHub Pages

## 2. 개발 목적

전공 공부와 여러 시험을 병행하다 보면 학습 자료별 진도, 복습할 범위, 시험일까지 남은 학습량을 파악하기 어렵습니다. 차곡차곡 2.0은 기존 1.0의 간편한 진도 기록 방식을 유지하면서 시험 관리, 학습량 추천, 이해도 기반 복습, 학습 통계를 한곳에서 제공하는 것을 목표로 합니다.

핵심 원칙은 **공부한 뒤 간편하게 기록하고, 다음 학습과 복습에 필요한 정보를 한눈에 확인하는 것**입니다.

## 3. 대상 사용자와 이용 환경

- **주 사용자:** 여러 교재·강의와 시험을 병행하는 대학생, 자격증·공무원 시험 준비생
- **사용 환경:** 스마트폰 중심, PC도 지원하는 반응형 웹앱
- **대표 사용자:** 전공 공부와 자격증 공부를 병행하며 복잡한 설정 없이 진도와 복습 상태를 관리하고 싶은 대학생

## 4. 핵심 요구사항 및 주요 변경

### 4-1. 학습 자료·진도·회독 관리 — 기존 기능 유지·확장

- 교재·문제집·인터넷 강의·단어 학습·기타 자료 등록, 수정, 삭제
- 자료별 단위·전체 학습량, 진도·진행률, 회독 및 과거 학습 기록 관리
- 범위별 부분 복습 기록, 자료별 메모, 목표 완료일, 직접 일시 중단
- 학습 자료 보관·복원 및 전체 데이터 백업·복원·초기화
- 기존 기록을 보존하면서 1.0의 학습 자료를 2.0 데이터 구조로 연계

- **[개선] 기록 관리:** 학습·복습 이력과 메모를 자료별로 더 쉽게 조회·수정하도록 구성

### 4-2. 시험 관리·학습량 추천 — 신규 핵심 기능

- 시험 등록·수정, D-Day, 시험별 학습 자료 연결 및 연결 해제

- 남은 학습량, 시험일·자료 목표일, 쉬는 날짜를 반영한 일일 권장 학습량

- 사용자가 직접 설정한 학습 계획 우선, 시험 중단·재개·보관·재응시 관리

- **[변경] 완료 기한 계산:** `자료 목표일 우선` → `자료 목표일과 시험 전날 중 더 이른 날을 기준으로 계산`
- **[변경] 시험 중단·마무리:** `자료별 유지 상태 사전 설정` → `중단·마무리 시점에 연결 자료별 계속 학습 여부 선택`
- **[추가] 쉬는 날짜 선택과 재응시 흐름:** 쉬는 날짜를 달력에서 지정하고, 재응시 시 선택한 기존 자료·이력을 연결
- **[개선] 오늘의 학습 추천:** 당일 실제 학습량을 반영하여 남은 권장량을 계산하고, 수동 계획 변경 시 새 기준으로 재계산

### 4-3. 이해도 기반 복습·시험 전 복습 — 신규 핵심 기능

- 학습·부분 복습 기록 시 이해도(쉬움·보통·어려움) 선택
- 학습 범위별 이해도와 복습 이력을 반영한 다음 복습일 계산
- 원본 기록을 보존하면서 겹친 범위에는 최신 이해도 반영
- 미완료·지연 복습 관리, 복습 예정일 수동 변경 및 실제 완료 후 재계산
- 여러 시험에 연결된 자료는 가까운 유효 시험일을 고려
- **[확정] 복습 간격:** 초기 미정 → 최초 1·3·7일, 이해도별 배수 0.5·1.5·2, 범위 1~180일의 승인 규칙 적용
- **[변경] 시험 전 집중 복습:** `시험일에 가까운 고정 기간 중심` → `실제 복습 속도·학습 가능일·여유일을 반영한 추천 시작일과 분량`
- **[추가] 일반·집중 복습 중복 통합:** 같은 범위의 추천을 묶어 표시하고 완료 이력은 중복 기록하지 않음
- **[개선] 복습 목록:** 오늘 예정/밀림을 구분하고 자료별 묶음 및 추가 조회 제공

### 4-4. 학습 현황·통계·캘린더 — 신규 핵심 기능

### 비교에서 확인되는 핵심 변화

- **1.0:** 공부한 진도와 회독, 부분 복습을 간편하게 **기록·관리하는 앱**
- **2.0:** 기록 기능을 유지하면서 시험 일정과 학습량을 연결하고, 복습을 자동 추천하며, 통계와 성장 이미지로 학습 상태를 **계획·확인하는 앱**으로 확장

**검증 범위:** 위 비교는 첨부 ZIP의 코드·화면 구성 및 2.0에 포함된 개발 문서를 근거로 합니다. 기존 1.0 사용자 데이터의 실제 무손실 전환, 최신 iPhone Safari·설치형 PWA·게시된 GitHub Pages에서의 동작은 이 ZIP 비교만으로 검증된 것이 아닙니다.
