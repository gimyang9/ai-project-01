# 승인 로고 실제 적용

선택한 균형 잡힌 픽셀 우드(previews/home-logo-v8/logo-refined.png)를 assets/home-logo-pixel-wood.png로 복사해 실제 홈 h1 이미지로 반영했습니다. 대체 텍스트 차곡차곡과 원본 크기 2078×757을 지정했습니다. 홈 보조 문구를 제거했고, dist에도 같은 에셋과 HTML/CSS 변경을 반영했습니다.

기존 홈 배너의 중복 height·aspect-ratio·object-position·로고 좌표 선언을 정리하고, 미리보기의 비례 배너 및 로고 규칙을 홈 전용으로 모았습니다. PC·태블릿은 3:1, 작은 모바일은 12:5이며 중간 폭은 높이와 로고 위치를 이어 줍니다. 날짜·인사 카드·버전과 내비게이션 규칙은 유지합니다. 기존 root/dist CSS의 관련 없는 차이는 보존했습니다.

새 임시 Chrome 프로필에서 실제 index.html과 앱 스크립트를 실행해 15개 너비(320~1920px)를 렌더링했습니다. 로고 로딩·영역 안 배치·PC 3:1 비율·보조 문구 제거를 확인했고 모바일390px·PC1024/1440px를 육안 검토했습니다. 사용자 브라우저 프로필은 사용하지 않았습니다. 앱 JS와 원본 숲 배너의 해시가 변경되지 않았으며 실제 사용자 저장값에 접근하지 않았습니다.

Chrome 모의 화면 검증이며 Safari 실기기 검증은 하지 않았습니다. 기존 미리보기와 에셋을 보존했고 Git 커밋·배포는 하지 않았습니다.
