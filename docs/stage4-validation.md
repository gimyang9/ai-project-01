# 4단계 — 이해도 기반 복습·시험 전 추천 검증

2026-10-25. 사용자 사례 승인 후 실제 앱과 dist에 반영했다. 자동 테스트 135개 통과, 임시 Chrome 프로필의 합성 자료로 5개 너비와 실제 폼 저장·재실행 흐름을 확인했다. 실제 사용자 백업이나 Safari 실기기 검증을 뜻하지 않는다.

## 확정한 정책

- 최초 어려움/보통/쉬움: 1/3/7일.
- 이후: 직전 간격 ×0.5/×1.5/×2, 반올림, 최소1·최대180일.
- 미선택은 보통 기준으로 계산하되 원본 평가를 채우지 않는다.
- POLICY 상수로 분리했다. 연속 성공은 파생 상태 내부에서만 계산하며 표시·필수 입력·백업 원본 필드로 추가하지 않는다.
- 최근 복습 기록 기간이 7일 미만이면 현재 회독에서 실제 학습한 분량의10% 올림을 초기 속도로 사용한다. 자료 전체 분량이 아니다.
- 기간7~13/14~27/28일 이상은 최근7/14/28일 평균, 미복습일도 포함한다. 충분한 기간의 최근 복습량0이면 초기값으로 대체하지 않는다.
- 같은 날짜 같은 자료의 겹친 복습량은 합집합으로 추정하며 실제 원본 기록은 그대로 남긴다.
- 수동 하루 복습량을 최우선한다.
- 예상 소요일은 실제 평균 속도로 계산한다. 표시·오늘 배정은 자료의 정수 단위로 올림하지만, 부족량 추정은 반올림된 표시 속도가 아닌 실제 평균을 사용한다.
- 여유일은 예상 소요일20% 올림, 최소1·최대7학습일. 사용자가 승인한 1번 제안의 상한을 유지한다.
- 시험 당일 제외, 요일·쉬는 날짜 제외 후 실제 학습 가능일을 거꾸로 센다. 직접 지정한 집중 시작일은 그대로 우선한다.
- 시작일이 지났으면 오늘부터 남은 기간을 계산한다. 어려운 범위, 오래된 범위를 우선하며 미학습 범위를 집중 복습에 넣지 않는다.
- 일반·시험 전 추천의 겹친 위치는 한 번만 표시한다. 합쳐진 범위의 복습 버튼도 한 번의 기록 저장만 수행한다.

## 이력·범위 처리

review-plan.js는 원본 기록을 수정하지 않는 파생 계산 모듈이다. 진도·부분 복습·과거 회독을 날짜/sequence/생성 시각/안정 순서로 재생한다. 1~30과20~50의 평가가 겹치면 교집합과 비교집합을 분리해 최신 평가를 반영한다.

진도 기록은 저장된 위치 차이로 실제 학습 구간을 구하며, 부분 복습은 그 시점까지 학습된 유효 구간에만 적용한다. 미래 기록과 다른 단위의 옛 기록은 자동 일정에 억지로 섞지 않는다. 회독별 원본 이력은 보존하고, 자료의 같은 범위에 대한 복습 기억은 회독이 바뀌어도 초기화하지 않는다. 집중 복습 대상과 초기10% 속도는 현재 회독 진도 안으로 제한한다.

수정·삭제 후에는 해당 자료의 이력으로 파생 상태를 다시 만든다. 각 사건은 겹치는 구간만 갱신하며, 관계없는 구간의 결과가 바뀌지 않는지 테스트한다. 완전한 차등 계산 캐시를 구현했다고 주장하지 않는다. 미완료 복습은 예정일을 미루지 않고 지연으로 남기며, 다음 일정은 실제 완료일에서 시작한다.

## 저장 호환성

저장 키 chagok-v2-data-v1, envelope version1, backupVersion1을 유지한다. reviewSettings는 자료의 선택형 추가 필드이며 옛 백업에 없어도 읽힌다.

- dailyAmount: 양의 정수 또는 null. 신규 학습 manualDailyAmount와 별개다.
- schedules: 범위·단위·날짜·지정일·지정 이후 sequence 경계를 저장한다.
- 수동 날짜는 자동 재계산으로 덮어쓰지 않는다. 지정 후 실제 복습을 완료한 구간에서만 적용을 소진한다. 기록을 삭제하면 원본 이력에 맞게 다시 계산된다.
- 날짜를 비우면 선택한 범위의 수동 지정을 해제하고 자동 날짜로 돌아간다. 겹치지 않는 수동 지정은 보존한다.
- 알 수 없는 기존 필드를 보존한다. 백업/복원 왕복, 저장 실패, 단위·회독·원본 이해도 유지 테스트를 실행했다.
- 시험 관리와 신규 학습 권장량 모듈은 구현 전후 해시가 동일하다.

## UI 연결

- 홈 오늘 복습할 범위: 실제 일반·지연·시험 전 통합 목록 개수.
- 목록 복습 기록: 시작/끝 자동 입력, 사용자는 날짜·이해도를 확인하고 한 번 저장.
- 앞으로의 복습 일정: 접을 수 있는 예정 목록과 범위별 날짜 변경.
- 자료 관리 → 복습 계획: 수동 하루 복습량, 초기/최근 기록/직접 지정 상태, 집중 시작일과 예상 부족량.
- 직접 집중 시작일은 기존 시험 수정 화면에서 정한다.
- 복습 날짜·계획 입력은44px 터치 높이와 자료별 실제 단위를 사용한다.
- 통계·캘린더는 여전히 예시이며 실제 데이터 연결은5단계다.
