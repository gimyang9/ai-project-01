## 승인 후 반영한 수정

- 다른 창 변경 시 저장을 차단한다. 입력·모달을 유지하고 새로고침 시 미저장 입력 손실을 안내한다. 자동 병합·덮어쓰기는 하지 않는다.
- 지원되는 HTTP/HTTPS 환경에서는 Web Locks로 동시 저장을 직렬화한다. 미지원 환경에서는 저장 전 비교를 사용하며 동일한 원자적 보장까지 주장하지 않는다.
- 집중 복습 시작 후 완료 범위를 보존한다. 다시 도래한 범위는 새 복습 대상으로 표시하며 원본 평가·완료 기록은 유지한다.
- 수동 시작일 변경은 새 대상으로 계산하고, 같은 시험의 시험일 변경은 진행 중 완료 범위를 유지한다. 재응시는 별도 시험으로 계산한다.
- 자정·다음 날 복귀 시 날짜별 화면을 갱신한다. 입력·열린 모달·저장 데이터는 유지한다.
- 작업 원본 배너를 배포본의 배경/오두막·곰 분리 구조로 통일했다. 기존 원본은 evidence/stage6/banner-before에 보존했다.
- CSS·진행 문서에 잘못 삽입된 문자 형태의 줄바꿈을 정리했다. CSS 수치는 유지했다.

학습 계획 모달도 승인 후 작업 원본 설정으로 통일했다. 내용 맞춤 높이·화면 높이 제한·세로 스크롤을 적용했다. 다른 모달은 유지했다. 166개 테스트와 Chrome390x840·1440x900·390x400 검증 통과. 근거: evidence/stage6/modal-browser-results.json, CG-SKILL-029.

보호 스킬의 점검 스크립트는 실행 정책으로 실행하지 못했다. 소스·저장 호출 직접 점검과 Node 해시 비교로 보조 확인하며 스크립트 실행 성공으로 기록하지 않는다.
