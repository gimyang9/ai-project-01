# 데스크톱 사이드바와 픽셀 정원 비교 시안

2026-10-24 사용자 요청 범위: 기존 기능·저장을 유지한 반응형 레이아웃 개선과, 앱에 적용하지 않는 일러스트 4종 비교.

## 레이아웃 적용

- 1024px 미만: 기존 하단 탭바와 모바일 스타일 유지. 새 브랜드/보조 영역은 숨긴다.
- 1024px 이상: 동일한 네 메뉴를 240px 왼쪽 고정 사이드바로 전환한다. 메뉴를 복제하지 않아 기존 클릭·활성 상태·aria-current 처리를 그대로 사용한다. 넓은 화면에서는 하단 탭바 형태가 표시되지 않는다.
- 사이드바: 크림색 배경, 26px 둥근 모서리, 옅은 그림자, 주아체 앱명과 부제, 연한 세이지 활성 메뉴, 하단 응원 문구/버전. 낮은 창에서는 스크롤 가능하다.
- 본문: 사이드바 오른쪽 280px부터 시작하며 본문 최대 폭은 1120px이다. 홈 배너의 양쪽 음수 여백을 데스크톱에서 제거하고 둥근 배너 안에 제한한다.
- 1024~1150px: 오늘 학습 아래 시험/복습 요약을 나란히 놓는다. 그 이상은 오늘 학습과 요약 스택을 2열로 배치한다.
- 학습 자료는 1024px 이상 2열, 1400px 이상 3열이다. 더보기는 제목과 설정/자료 보관함 카드를 공통 680px 기준선에 맞춘다. 메뉴 수는 그대로다.
- 앱 JavaScript·저장 키·데이터 구조는 변경하지 않았다. 루트/dist HTML·CSS를 동기화했다.

## 적용하지 않은 일러스트 시안

비교 페이지: `previews/sidebar-art/index.html` 및 게시 폴더의 `dist/previews/sidebar-art/index.html`.

| 파일 | 시안 |
|---|---|
| 01-bear-tree.png | 작은 나무와 크림색 아기 곰 |
| 02-growing-garden.png | 새싹과 꽃이 자라는 작은 정원 |
| 03-woodland-cabin.png | 나무와 꽃에 둘러싸인 목재 오두막 |
| 04-study-garden.png | 책·화분·연필과 책 읽는 곰의 공부 정원 |

내장 image_gen 도구를 시안마다 한 번씩 사용했다. `assets/forest-bear-b.png`와 `assets/plants-five-stages.png`를 먼저 열어 확인하고 스타일 참고로 전달했다. 기존 에셋은 수정하거나 덮어쓰지 않았다. 각 파일은 1448×1086 투명 배경 PNG다. 생성 원본의 알파를 유지하고 CSS image-rendering:pixelated로 표시한다. 최종 프롬프트는 시안 폴더의 `prompts.json`에 보관했다.

비교 페이지는 사이드바 전체 4개를 나란히 보여주며, 기본 폭 240px/일러스트 192px, 슬롯 높이 168px, 문구 간격 12px로 구성했다. 사이드바 220~260px와 이미지 160~208px를 조절하고 체크무늬 배경으로 투명도를 확인할 수 있다. 좁은 화면에서는 비교 목록 자체를 2열 또는 1열로 바꾼다. 앱의 JavaScript를 불러오지 않고 브라우저 저장소에도 접근하지 않는다. 실제 앱은 이 시안 파일들을 참조하지 않는다.

## 검증과 한계

- 기존 데이터/시험/앱 모의 DOM 테스트 56개 재실행, 모두 통과: `docs/evidence/sidebar-tests.tap`.
- 전후 경계 점검: reference/v1 6개 파일 및 dist 앱 JavaScript 해시 동일. `sidebar-boundary-before.json`, `sidebar-boundary-after.json` 참조.
- 시안 네 파일을 열어 주제·구도·참고 에셋과의 조화를 확인했다. PNG 알파를 12px 간격으로 샘플링해 네 파일 모두 완전 투명 픽셀과 실제 그림 픽셀이 있음을 확인했다. 원본 알파는 수정하지 않았다: `sidebar-art-alpha.json`.
- 비교 페이지의 인라인 JavaScript 구문 검사 통과. 앱의 네 메뉴 유지, CSS 괄호와 반응형 분기, 루트/dist 일치, 실제 앱의 시안 미참조를 정적으로 확인했다: `sidebar-summary.json`.
- 현재 cua.getState()는 apps=[], browsers=[]이다. 실제 390/768/1023/1024/1280/1440px 화면, 낮은 창, 탭 전환/키보드 포커스의 브라우저 검증은 수행하지 못했다. 정적 구조 확인과 모의 DOM 테스트를 화면 QA로 주장하지 않는다. 실제 Safari/PWA도 미검증이다.
- 사용자가 선택하기 전 일러스트는 앱에 적용하지 않는다. 3단계 기능·배포·Git 커밋은 진행하지 않았다.

## 2026-10-25 최종안 1번 실제 앱 적용

사용자가 1번을 최종 선택하여 원본 PNG를 assets/sidebar-bear-tree.png 및 dist/assets/sidebar-bear-tree.png에 그대로 복사했다. 기존 4종 시안과 홈/성장 에셋은 보존했다. 앱 HTML의 하단 잎사귀 장식을 선택된 이미지로 교체했고, 모바일에서는 picture source의 media 조건이 투명 1px 대체 이미지로 전환되며 하단 장식 전체가 CSS로 숨겨진다.

이미지 폭 208px 지정(시안 192px 대비 약 8.3%, 사이드바 실제 가용 폭 206px에서는 약 7.3%), 4:3 비율과 pixelated 표시 유지. 이미지 아래 margin 5px, footer 위 padding 24px로 문구를 가깝게 배치했다. 버전은 16px 여백과 옅은 구분선으로 footer 맨 아래에 배치했다. footer는 margin-top:auto와 flex:none으로 이미지가 찌그러지지 않도록 구성했다. 높이 650px 이하에서는 이미지 192px·위 여백 14px·버전 간격 축소로 메뉴 공간을 확보하며, 더 낮은 창은 기존 사이드바 자체 스크롤로 접근한다.

본문 간격도 정적으로 검토했다. 사이드바 오른쪽 260px와 본문 시작 304/312/320px 사이에 44/52/60px의 여유가 있어 기존 데스크톱 정렬을 유지했다. 모바일 내비게이션·앱 JS·저장 로직 변경 없음. 루트/dist 동기화 완료.

기존 자동 테스트 56개 재실행 모두 통과, 앱 JS/1.0 보존 파일 전후 동일, 선택 원본과 적용 에셋 해시 동일. 근거: docs/evidence/sidebar-final-summary.json, sidebar-final-before.json, sidebar-final-after.json, sidebar-final-tests.tap. 현재 cua.getState()는 apps=[], browsers=[]라 실제 데스크톱 홈 화면/모바일/낮은 창 시각 검증은 미수행이다. 구현 완료와 실제 화면 확인 대기를 구분한다. 커밋·배포 없음.
