## 2026-11-02 승인: 계획 예상·실제 속도 예상·목표일 분리

이번 사용자 설계가 앞선 자동 모드의 예상일 정책에 우선한다. `planForecast`는 자동 권장량 또는 직접 설정량과 학습 가능일로 계산하고, `actualForecast`는 현재 회독의 실제 기록 평균으로 계산한다. 목표 완료일은 사용자가 입력한 날짜이며 계산된 예상일로 덮어쓰지 않는다.

- 홈·자료 상세의 계획 카드는 계획상 예상일 하나만 표시하고 ‘계획한 학습량 기준’을 덧붙인다. 목표일은 하단에서 별도로 보여 준다. 계획이 유효 기한보다 늦으면 날짜를 그대로 표시하고 짧게 안내한다.
- 자동·수동은 같은 계획 예측 함수를 사용한다. 오늘의 남은 용량을 먼저 반영하고, 이후에는 학습 가능한 요일·쉬는 날짜를 센다. 자동 재계산 전에 이미 반영한 오늘 학습량(`creditedBefore`)을 다시 차감하지 않는다. 하루10·남은100·오늘 포함 매일 학습이라면2026-11-02 기준11-11에 완료하는 계획이다.
- 하루 학습량 설정은 숫자 입력을 유지한다. 입력마다 저장 전 예상일·목표일·지연 안내를 갱신하고, 저장 전에는 실제 설정·기록·저장소를 바꾸지 않는다. 비우면 자동 추천, 잘못된 값은 안내하고 저장하지 않는다. 취소·닫기는 기존 설정을 유지한다.
- 통계는 실제 평균 속도와 실제 속도 예상일을 중심으로 계획상 예상일·목표일을 함께 비교한다. 현재 회독 기록7일 미만이면 실제 속도 예측만 숨긴다. 과거 회독·복습 기록은 그대로 보존하며 기존 기간 통계 집계도 유지한다. 실제 속도의7/14/28일 평균은 공부하지 않은 날을 포함한다.
- 목표일/유효 시험 기한 없이 자동이면 권장량 안내를 요청하고 날짜를 만들지 않는다. 직접 설정은 기한 없이도 계산한다. 쉬는 날은 오늘량0이지만 이후 일정으로 예상하며, 완료는 ‘이번 회독 완료’, 중단은 계획일 비활성화 후 재개 시 재계산한다. 유효 기한·다중 시험·우선 시험·수동 설정 보존 정책은 유지한다.

계획/실제 예상일은 조회용 파생값으로 저장하지 않는다. 저장키·버전·원본기록·사용자 목표일·회독·복습 데이터는 유지한다. [구현과 검증](integrated-management-update.md).

## 2026-11-02 승인: 직접 설정한 하루 분량 기준 예상일

학습 계획에서 수동 하루 분량이 있으면 남은 분량·오늘 남은 설정량·학습 가능한 요일/쉬는 날짜로 예상 완료일을 계산한다. 오늘 이미 기록한 양은 남은 분량과 오늘 용량에 반영하며 중복 차감하지 않는다. 오늘 가능한 분량으로 완료할 수 있으면 오늘, 아니면 다음 학습 가능일부터 센다. 시험 전날/목표일을 넘는 예상일도 그대로 표시해 지연을 안내한다.

입력을 비워 자동 추천으로 돌아가면 종전 실제 기록 기반7/14/28일 평균 예상일을 사용한다. 통계의 실제 속도·실제 기록 기준 예상일은 유지한다. 학습 계획의 수동 예상과 통계의 실제 속도 예상은 기준이 다르다. 학습 가능 요일이 없거나 날짜 범위를 넘으면 예상일을 만들지 않는다. 초기 기록7일 미만이어도 직접 설정한 분량으로는 계획 예상일을 계산할 수 있다.

이는 아래 과거 “예상일은 수동 분량과 별개” 정책 중 학습 계획의 수동 모드에 우선한다. 저장키/버전·원본기록·수동분량·시험/복습 일정은 변경하지 않는다. [구현·검증](integrated-management-update.md).

## 시험 관리

- 시험 날짜는 선택 입력으로 한다. 날짜가 없으면 시험일 미정으로 표시하며 D-Day를 표시하지 않는다. 확정/예상/미정 상태 선택 UI는 제거한다.
- 낮음/보통/높음 중요도는 제거하고 동시에 하나만 지정 가능한 우선 시험으로 대체한다. 우선 시험은 목록·추천 순서에 우선 반영한다.
- 하단 탭과 시험 관리 화면 명칭은 ‘시험’으로 통일한다. 일반적인 일일 학습 목표는 시험으로 치환하지 않는다.
- 시험 관리 메뉴: 메모, 시험 수정, 우선 시험 지정/해제, 마무리·보관, 중단/다시 시작, 삭제.
- 자료에 미리 ‘시험 중단 시 학습 유지’를 설정하지 않는다. 시험 중단/마무리 시 연결 자료별로 계속 학습할 항목을 선택한다. 매번 모두 미선택이 기본이다.
- 다른 활성 시험이 하나라도 있는 연결 자료는 계속 활성 상태로 유지한다. 사용자가 자료 자체를 직접 중단한 상태가 항상 우선한다.
- 재개 시 해당 시험 때문에 자동 중단됐던 자료만 복원한다. 연결 관계와 원본 학습·복습·회독 이력은 보존한다.
- 중단 모달은 시험명을 설명 문장에 통합하며 내용에 맞는 높이를 사용한다. 긴 경우 선택 목록만 스크롤한다.

## 시험 전 집중 복습: 고정 D-7 방식 사용 금지

- 시험 D-Day, 남은 분량, 범위별 이해도, 복습 이력, 지연 상태, 실제 학습 속도와 학습 가능일을 함께 고려한다.
- 복습 기록이 충분하면 과거 복습 분량으로 속도를 추정한다. 타이머나 새로운 필수 입력은 추가하지 않는다.
- 기록 부족 시 초기 추정값을 사용하되 추정임을 안내한다.
- 개인별 예상 복습 소요일과 여유일로 시작일을 추천한다. 초기 추정량과 여유일 적용 기준은 구현 전에 테스트 사례로 사용자 확인을 받는다.
- 시간이 부족하면 우선 범위와 예상 부족량을 제시한다. 모든 범위를 무리하게 배정하지 않는다.
- 일반 복습은 유지하며 시험 전 계획을 별도로 만든다. 같은 날 같은 범위는 추천을 통합하고 실제 이력은 한 번만 기록한다.
- 실제 복습 후 남은 분량과 추천 일정을 조정한다. 수동 계획·복습 날짜는 우선 보존하며 추천을 수정할 수 있다.
- 과학적 학습 원리와 앱 자체의 경험적 규칙을 구분한다. 개인별 최적 날짜를 보장하지 않는다.
- 최초 복습 간격, 증가·감소율, 장기 제한, 예측 기간과 초기 추정량의 구체 수치는 아직 확정하지 않았다. 이전 제안 수치를 확정값으로 구현하지 않는다.

## 학습·복습 표시

- 부분 복습의 누적 횟수, 총 N회, 복습1회, 반복 ‘복습 범위’ 라벨을 표시하지 않는다. 날짜와 범위만 보여준다.
- 자료별 메모는 한 개씩 고유 ID와 연결해 저장한다. 메모 존재 배지·점·미리보기 등은 표시하지 않는다.
- 진도 기록의 현재 위치 입력은 최초 진입 시 비워 둔다. 입력 오른쪽에 `/ 전체 분량 단위`를 한 줄로 표시한다.
- 각 자료에 실제 저장된 단위를 사용하고 기존 범위의 숫자는 변환하지 않는다.
- 기록 내역은 날짜/수정·삭제 한 줄, 왼쪽 학습량(+표시)/오른쪽 현재 위치 한 줄로 표현한다.
- 선택 항목은 `항목명 (선택사항)`으로 통일한다.
- 홈 오늘의 학습은 신규/권장 진도만 보여준다. 복습은 별도 요약과 복습 목록에서 확인한다.
- 복습 상태명은 복습 예정 / 복습 지연 / 시험 전 복습으로 통일한다.
- 학습 유형 5종은 드롭다운으로 선택한다.
