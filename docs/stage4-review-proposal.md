# 4단계 복습 정책 제안 — 사용자 확인 전 초안

2026-10-25. 이 문서는 구현된 계산 규칙이 아니라 검토용 제안이다. PRD-updates.md의 ‘구체 수치는 아직 확정하지 않았다’에 따라 승인 전 자동 계산에 연결하지 않는다.

## 먼저 확인한 구현
- 진도/부분 복습 기록에 쉬움·보통·어려움 또는 미선택을 이미 저장한다.
- 기록 수정 시 ID·생성 시각·sequence와 미지 필드를 보존한다.
- 다음 회독은 과거 진도와 이해도 및 부분 복습 이력을 보존한다.
- 이번에는 저장 정책을 변경하지 않고 이 경계를 합성 테스트 5개로 보강했다. 기존 테스트 포함 100개 통과.
- scripts/inspect-boundary.ps1은 현재 작업 폴더에 없다. 실행했다고 주장하지 않으며 직접 소스 검토와 해시를 보조 근거로 사용한다.

## 확인 1 — 일반 복습 간격
앱의 경험적 초기 설정이다. 개인별 최적 복습일을 의미하지 않는다.
- 최초 평가: 어려움 1일, 보통 3일, 쉬움 7일.
- 다음 평가: 해당 구간의 직전 간격에 어려움 ×0.5, 보통 ×1.5, 쉬움 ×2를 적용하고 일 단위로 올림한다.
- 최소 1일, 최대 180일. 수개월 간격을 허용하되 무제한으로 늘리지 않는다.
- 기한을 놓쳐도 예정일을 밀지 않고 ‘복습 지연’을 유지한다. 실제 완료일에 다음 간격을 더한다.
- 미선택은 보통과 같은 기본 간격을 쓰되 원본 이해도를 ‘보통’으로 채우지 않는다. UI에서도 사용자가 보통을 선택한 것처럼 표시하지 않는다.
- 수동 날짜가 있으면 자동 예정일보다 우선하며 원본 평가와 분리해 저장한다.

| 직전 간격 3일 후 평가, 어려움 / 보통 / 쉬움 | 2일 / 5일 / 6일 |

## 범위와 이력 — 제안한 연결 방식
- 1~30 이후 20~50을 기록하면 1~19 / 20~30 / 31~50으로 나누어 교집합에만 최신 평가를 반영한다.
- 겹친 구간은 기존 복습 이력을 승계하고, 처음 등장한 구간만 최초 간격을 적용한다.
- 자료 ID·단위별로 관리한다. 회독이 바뀌어도 같은 자료 범위의 복습 기억을 초기화하지 않고 최신 학습/복습 평가를 반영한다. 원본 회독별 기록은 그대로 둔다.
- 같은 날짜는 저장 sequence 순서로 처리한다. 기존 데이터의 동일 sequence 충돌은 createdAt, 마지막으로 원본 배열 순서를 보조 기준으로 삼아 결정적 순서를 만든다.
- 과거 평가 수정·삭제 시 해당 범위만 원본 이력으로 재생한다. 저장된 날짜와 원본 평가 자체를 변형하지 않는다.
- 자료 전체 분량이나 단위가 다른 옛 기록은 임의로 비율 환산하지 않는다. 단위가 같은 유효 범위에만 적용하고 확인 불가능한 범위는 별도로 안내한다.

## 확인 2 — 시험 전 복습 속도와 기록 부족
- 실제 부분 복습 기록의 기간이 7일 미만이면 기록 부족으로 판단한다.
- 7~13일은 최근7일, 14~27일은 최근14일, 28일 이상은 최근28일 평균을 사용하고 쉬었던 날도 분모에 포함한다.
- 같은 자료에서 같은 날 겹친 범위는 합집합으로 계산해 추천 속도가 중복 범위 때문에 부풀지 않도록 한다.
- 기록 부족일 때만 자료 전체 분량의 10%를 올림한 양을 임시 하루 속도로 제안한다. 자료별 실제 단위를 그대로 쓰고 ‘초기 추정’임을 표시한다.
- 기록 기간이 충분하나 최근 기간에 복습량이 0이면 초기값으로 대체하지 않는다. 속도 미정으로 표시하고 수동 계획을 우선한다.
- 사용자가 직접 지정한 복습량은 항상 우선한다.
- 신규 학습 속도와 복습 속도를 혼합하지 않는다.

사례:
| 상황 | 제안 결과 |
| --- | --- |
| 100페이지 자료, 복습 기록 3일, 복습 대상 60페이지 | 초기 추정 10페이지/일, 6학습일 |
| 25강 자료, 기록 부족, 복습 대상 15강 | 초기 추정 3강/일, 5학습일 |
| 기록 기간 10일, 최근7일 합집합 총70페이지 | 10페이지/일 |
| 기록 기간 30일, 최근28일 복습0 | 날짜 계산 안 함, 속도 미정 안내 |

‘자료 전체 분량의 10%’는 단위 간 절대 분량을 비교하지 않는 초기 휴리스틱이며 검증된 개인별 능력이 아니다. 사용자가 바꿀 수 있게 한다.

## 확인 3 — 집중 복습 여유일
- 예상 소요일 = 복습 대상 비중복 분량 / 하루 복습 속도를 올림.
- 여유 학습일 = 소요일의 20%를 올림, 최소1일·최대7일.
- 시험 당일은 제외하고, 연결 시험 중 가장 가까운 유효 시험의 요일·쉬는 날짜에 따라 필요한 학습일만큼 뒤로 센다. 고정 D-7/D-14로 대체하지 않는다.
- 예: 대상60페이지, 속도10페이지/일 → 6학습일 + 여유2학습일, 시험 전 8번째 학습 가능일부터 추천.
- 남은 학습 가능일이 4일이면 40페이지를 배정하고 부족20페이지를 표시한다. 하루 양을 몰래 늘려 완주를 보장하지 않는다.
- 여러 자료에 대한 하루 총 공부 시간은 알 수 없으므로 일정 충돌을 완전히 해결한다고 안내하지 않는다.
- 새로 배우지 않은 범위는 복습 대상으로 임의 추가하지 않고 기존 신규 학습 계획에서 다룬다.
- 같은 날 같은 자료의 일반·시험 전 추천은 합집합으로 표시하고 완료 기록을 한 번만 만든다.
- 중단/보관 자료는 자동 추천에서 제외한다. 직접 중단과 수동 일정은 자동 추천으로 덮어쓰지 않는다.
