오른쪽 가장자리를 잡고 배너를 늘려 보세요.

실제 배너 이미지·로고·앱 CSS를 사용합니다. 승인된 개선 배너를 실제 홈 화면과 배포본에도 적용했습니다. 기존 배너는 적용 전 비교용입니다.

배너 실제 너비 확인 중…개선 배너 · 브라우저 연동배경 확인 중

오른쪽 세로 손잡이를 드래그하면 수동 너비 조절로 바뀝니다. ‘브라우저 너비에 맞춤’을 켜면 창 크기를 변경하는 대로 배너도 따라갑니다. 전체 화면을 축소하지 않는 1:1 CSS 픽셀 표시입니다.

↔

확인 방법

  1. 기존/개선 배너를 전환해 빈 영역과 로고 배치를 비교합니다.
  2. 손잡이를 천천히 드래그하거나 767·768px 버튼을 눌러 경계를 비교합니다. 손잡이에 초점을 두고 방향키를 누르면1px씩, Shift와 함께 누르면10px씩 바뀝니다.
  3. 브라우저 연동을 켜고 브라우저 창 자체를 늘리고 줄입니다. 브라우저 확대·축소도 그대로 사용할 수 있습니다.
  4. ‘실제 앱 배치’에서는 기존1024px 사이드바 전환과 본문 최대 너비가 적용됩니다. 따라서 프레임 너비와 배너 실제 너비가 다릅니다.

빈 영역 표시는 이미지 사각형이 배너를 덮는지 실시간으로 계산합니다. 그림 안의 하늘 색상이나 장식의 투명 부분을 빈 영역으로 판정하지 않습니다. 최종 구도의 자연스러움은 화면에서 함께 확인해 주세요.
