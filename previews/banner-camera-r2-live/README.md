# R2 배너 실시간 검토

프로젝트 폴더를 VS Code에서 열고, 이 폴더의 **index.html**을 오른쪽 클릭 → **Open with Live Server**로 실행합니다.

기본 포트 예시:
http://127.0.0.1:5500/previews/banner-camera-r2-live/index.html

- 오른쪽 손잡이: 드래그 너비 조절
- 브라우저 너비에 맞춤: 창 크기 변경과 연동
- 기존/개선: 같은 프레임에서 즉시 비교
- 배너 단독/실제 앱 배치: 컨테이너 자체와 앱 레이아웃을 구분
- 프레임은 축소하지 않으며, 실제 CSS 너비를 표시합니다.

2026-10-26 최종 승인 후 같은 카메라 CSS를 실제 앱과 배포본에 적용했습니다. 이 페이지는 읽기 전용 비교 도구로 유지합니다.
